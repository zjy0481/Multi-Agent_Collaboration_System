# T005 在私有工作区执行并交接版本

## 交付与边界

为登记角色及助手接通文件、代码测试、资料检索工具适配接口与不可变产物发布。交接绑定版本和读者，含读取或导入获准副本。

规格契约见 [S003](../specs/S003.md) · [S001](../specs/S001.md)。

<a id="acceptance"></a>

## 验收

用测试传输验收搜索来源记录及取回结果。第三成员无法访问私有草稿或宿主凭据。获准读者能打开指定旧版并在隔离空间测试。验证命令超时、失败清理与路径范围。

首次实际集成时记录技术版本、许可证与对应验收证据。
