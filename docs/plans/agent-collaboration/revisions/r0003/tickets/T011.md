# T011 按真人批准执行 Git 推送

## 交付与边界

交付任务内 Git 提交及推送申请、真人审批、持久领取、原调用关联和远端核对。用可控的本地 Git 远端核验写入语义。

规格契约见 [S001](../specs/S001.md) · [S002](../specs/S002.md) · [S003](../specs/S003.md)。

<a id="acceptance"></a>

## 验收

拒绝及仓库、ref、SHA、动作不匹配时阻止推送。批准后重放只产生一条动作记录。模拟批准后重启和远端结果未知，按对应 ref 核对并回传。
