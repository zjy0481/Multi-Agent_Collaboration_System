# T002 发送群聊与私聊并恢复可见消息

## 交付与边界

交付消息发送、点名唤醒、双方私聊、快照和 SSE 续读。定向投递与消息同事务持久化为可领取待办。Lead 可按原始消息登记一个活动或排队目标，供委托和报告引用。用 Lead、目标成员和另一成员对照公共读者与定向投递。

规格契约见 [S001](../specs/S001.md)。

<a id="acceptance"></a>

## 验收

断线后按游标补发，失效游标刷新快照。重复发送只产生一个消息和一组去重后的投递。进程重启后仍可读取待领取记录。重复登记原始布置仅产生一个目标，并验证同组的第二项目标进入队列。未获权成员的消息查询、快照和 SSE 均看不到受限内容。
