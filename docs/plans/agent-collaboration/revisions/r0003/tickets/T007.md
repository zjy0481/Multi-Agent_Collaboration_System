# T007 从历史回合派助手完成一次受限协作

## 交付与边界

交付定点分支、历史投影、助手的独立待办和范围内的直接答疑。覆盖首次协商、既有修订、撤权以及父代理采用证据。

规格契约见 [S001](../specs/S001.md) · [S002](../specs/S002.md) · [S003](../specs/S003.md)。

<a id="acceptance"></a>

## 验收

从第 2 回合建分支，只读获准历史及版本，第 3 回合材料须显式交接。父子执行时段可重叠。首次草案、旧修订冲突、撤权、重放去重及授权正反例均有证据。让接手方在指定范围内直接联系派发方助手答疑，验证只有获准联系人可投递。记录父代理采用或退回的决定及来源引用。

- [T004](T004.md#acceptance) 提供首次协商和既有任务修订。
- [T005](T005.md#acceptance) 提供授权材料版本和助手工作区。
- [T006](T006.md#acceptance) 提供成组回合、领取、代次和独立模型推进。
