# T013 联调课程端点与真实工具

## 交付与边界

验证课程发放的模型、凭据、配额和工具调用协议，接通获准的实际检索来源。核验真实 GitHub 推送另见 T016。

规格契约见 [S002](../specs/S002.md) · [S003](../specs/S003.md)。

<a id="acceptance"></a>

## 验收

记录课程端点的两步真实工具调用，第二次使用第一步真实工具结果。验证来源可追溯、认证失败和真实运行模式，保存适用协议和版本证据。

附加验证使用课程模型完成一次缺省 Lead 的建组路径，真实工具调用与离线替身的结果分别留存。
