# T003 处理真人澄清与重启接续

## 交付与边界

支持目标登记前提问、按引用优先接收回复、持久化阻塞与继续投递。记录用户修正旧决定后对引用者的通知。在最小工作记录夹具上验证阻塞投影，真实并行执行由 T014 验证。网页按线程显示待答问题和对应答复入口。

规格契约见 [S001](../specs/S001.md) · [S002](../specs/S002.md)。

<a id="acceptance"></a>

## 验收

两项工作同时待答，重启后引用其中一项，答复只解除该问题的阻塞。独立待办保持就绪，测试以持久记录和受控领取夹具观察状态。获准用户能从网页定位并回复待答问题。引用答复优先于点名，重复答复不重复恢复。

- [T002](T002.md#acceptance) 提供消息写入与引用投递。
