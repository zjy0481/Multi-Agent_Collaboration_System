# T009 关闭或终止目标并激活下一项

## 交付与边界

交付目标验收约定修订、必需交付校验、终态及冻结事实的原子写入、登记前终止和 Lead 激活下一目标。

规格契约见 [S001](../specs/S001.md) · [S004](../specs/S004.md)。

<a id="acceptance"></a>

## 验收

必需交付未通过时无法成功关闭。结束后 Lead 收到通知并选择队列中最早合格项。复现登记前终止、在途助手和迟到答复，核对冻结事实及独立关联。分别触发 failed、timed_out 和 cancelled，核对操作者、原因或用户理由、服务端时间和可适用的证据。

## 依赖

- [T003](T003.md#acceptance) 提供人类问题的阻塞和撤销关联。
- [T008](T008.md#acceptance) 提供当前通过证据和下游待复核。
- [T007](T007.md#acceptance) 提供分支撤权和助手终止。
