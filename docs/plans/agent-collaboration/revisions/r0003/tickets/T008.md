# T008 提交版本并完成局部返工

## 交付与边界

交付负责人提交、主审通过或退回、下游待复核和向结案提供的当前有效验收事实，并在最小网页展示任务的交付详情与审查证据。

规格契约见 [S001](../specs/S001.md) · [S003](../specs/S003.md)。

<a id="acceptance"></a>

## 验收

主审退回 v1，原任务重交 v2。独立任务保留通过，依赖 v1 的任务待复核。旧验收无法满足本轮结案，通知和受审版本可追溯。获准读者从网页打开版本、审查决定和认可依据，验证旧版仍可读且和实际受审版本对应。

## 依赖

- [T004](T004.md#acceptance) 提供任务 ID、有效修订、提交人和审查人关系。
- [T005](T005.md#acceptance) 提供不可变产物的发布与获准读取。
