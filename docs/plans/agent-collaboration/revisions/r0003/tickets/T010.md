# T010 从业务事实生成可重算报告

## 交付与边界

交付单目标及按布置集合汇总的权限投影、原始计数、耗时、等待人工、运行模式和审查引用。

规格契约见 [S004](../specs/S004.md)。

<a id="acceptance"></a>

## 验收

令一项已交付、一项失败、一项登记前终止，重算目标 1/3。用返工和未确认草案重算子任务 2/3，核对零分母、重放去重、等待区间和越权报告。另用失败、超时和带用户理由的终止记录验证报告分别分类并保留原因与时间。
