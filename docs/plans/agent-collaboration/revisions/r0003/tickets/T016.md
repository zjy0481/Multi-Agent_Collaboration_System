# T016 验收一次获准的 GitHub 交付

## 交付与边界

用课程项目获准仓库和真人批准验证 GitHub 推送，保存实际远端 ref、提交 SHA 和动作回执。

规格契约见 [S003](../specs/S003.md)。

<a id="acceptance"></a>

## 验收

将获准提交推到指定 ref 后读取远端核对，验证真实回执。将禁止以及参数不匹配的案例留作 T011 的可重复验证证据。

## 依赖

- [T011](T011.md#acceptance) 提供宿主的 GitHub 绑定批准及回执。
- 真实 GitHub 验收仓库、目标 ref 及真人批准可用。 [外部条件](../review.md#external-conditions)
