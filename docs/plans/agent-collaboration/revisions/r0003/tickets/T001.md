# T001 导入角色并建立可用团队

## 交付与边界

实现角色文件校验、过渡建组、初始团队契约、主会话和最小 Docker 工作区准备，交付团队导入入口及成员清单。用受控建组替身复现过渡代理路径，真实课程端点的对应验证由 T013 承担。

规格契约见 [S001](../specs/S001.md) · [S002](../specs/S002.md) · [S003](../specs/S003.md)。

<a id="acceptance"></a>

## 验收

导入三组角色及一个无明显 Lead 的变长清单。验证原角色提示、文件错误位置、过渡代理只创建一个 Lead 后退出。增员准备成功后才发布契约修订。并发或重试不重复创建成员、会话和工作区。
