# T017 运行中期与期末闭集评测

## 交付与边界

按课程实际发放的中期和期末闭集及条件运行正式评测，形成性能和失败分析、经验演进及可重算结果。

规格契约见 [S004](../specs/S004.md)。

<a id="acceptance"></a>

## 验收

逐次记录数据集、实际模型、代码版本及模式，重算子任务和目标完成率与执行时间。保留失败、等待、经验采用及对照限度。

## 依赖

- [T013](T013.md#acceptance) 提供实际端点、模型和工具传输。
- [T014](T014.md#acceptance) 提供可报告且通过协作联验的完整基线。
- 中期及期末闭集输入、发放和评测安排已明确。 [外部条件](../review.md#external-conditions)
