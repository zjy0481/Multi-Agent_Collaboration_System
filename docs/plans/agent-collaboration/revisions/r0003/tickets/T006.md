# T006 用可重复的工具回合驱动持久待办

## 交付与边界

消费 T002 已持久化的消息待办，交付 Python 模型适配、显式离线替身、持久调度、原调用 ID 回执和运行代次。加入故障中断、旧代次拒绝与恢复。

规格契约见 [S002](../specs/S002.md) · [S001](../specs/S001.md)。

## 验收

运行两个有依赖关系的工具调用，第二次消费第一次结果。同一会话只有一个推进回合，独立会话有并行证据。重启不重复已生效动作，正式模式缺配置报错。

首次实际集成时记录技术版本、许可证与对应验收证据。
