# T014 贯通协作、权限与故障恢复验收

## 交付与边界

在同一集成版本进行可重复的端到端联验，覆盖局部用例叠加后才能证明的安全边界、恢复和指标。

规格契约见 [S001](../specs/S001.md) · [S002](../specs/S002.md) · [S003](../specs/S003.md) · [S004](../specs/S004.md)。

## 验收

组合验证分支、并发、草案、私聊、两个待答问题、重启、推送核对、局部返工、队列和 1/3、2/3 计数。用同一获准材料和受限材料的正反例逐项核对快照与 SSE、模型输入、附件、检索、回放、经验和导出。核对网页可用的交付详情和获准审查证据。记录输入、失败条目及实际证据。

汇总已采用组件的精确版本、来源、许可证和验证索引，覆盖 FastAPI、SQLite、Docker、Git 及实际锁定的其他依赖。单列 OpenClaw、LangGraph、DeepSeek Harness、Codex、Pi 与 OpenHands 的参照机制和源码入口。实际改编的部分记录固定提交、许可证、改动及对应证据。真实课程联调的版本证据由 T013 提供。
