# S002 模型运行、历史检查点与助手分支

## 范围与需求来源

把持久待办推进为可恢复的模型回合，支持同一执行会话串行、不同会话并行，以及从任意获准的已完成回合派出助手。边界以定稿历史分支、跨参与者隔离、真实模型及其验收场景为准。 [定稿需求](../../../../../grill_result/agent-collaboration/requirement.md#验收场景) · [运行时历史分支](../../../../../grill_result/agent-collaboration/runtime-contract.md#指定历史回合分支)

## 调度和模型工具契约

- SQLite 持久记录待办、工作范围、会话、回合、运行代次和工具回执。调度器原子认领就绪工作，同一执行会话一次只推进一个回合，助手有独立运行槽。等待真人或容量时可见对应原因。模型下一次决策前装配在本会话可见的已送达输入。 [S001 公共契约](S001.md#shared-contract) · [OpenClaw 队列参考](https://docs.openclaw.ai/concepts/queue)
- 课程模型适配器接收获准消息、工具参数结构和预算，回传角色消息或原调用 ID 对应的工具调用。模型、助手、摘要和辅助调用均使用同一允许的课程端点配置。宿主工具执行前校验参数、当前范围及运行代次，回执持久化后再以原调用 ID 返回模型。记录实际端点、模型、模式和调用事实。离线模式用显式 mock，正式模式配置缺失或认证失败时返回失败原因。首版用 Python 工具循环，HTTPX 是隔离传输与离线测试的候选依赖。 [DeepSeek 工具调用](https://api-docs.deepseek.com/guides/tool_calls/) · [DeepSeek Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/) · [HKGAI Modelhub](https://hkgai-studio.prod.hkchat.app/en/docs/modelhub)
- 回合完成要求模型消息、成组的工具调用与结果及结束边界均已持久化。中断或未知状态保留已有记录。重启以持久待办和已生效工具回执为准，隔离旧运行代次。从可安全接续的位置继续，未知副作用移交工具执行方核对。已终止范围的迟到结果只进审计事实。 [S003 外部动作](S003.md#external-actions)

## 检查点和助手交接

- `GET /v1/sessions/{id}/turns` 返回可访问父会话的可选已完成回合。`POST /v1/sessions/{id}/forks` 接受指定回合、活动目标、首次协商或既有任务范围、目的、授权材料版本、工具、联系人、接收者及请求键。成功在同一事务固化父回合末端、当时适用的任务修订和材料引用，创建子会话及首个待办，并返回稳定回执。草案协商范围由 S001 提供，既有任务使用有效修订。 [S001 委托](S001.md#delegation)
- 首次及后续决策均按工作范围、创分支时授予的来源范围与当前权限取交集。仅继承截至检查点且获准的历史，工具调用和结果按组保留。不能安全分组时省略整组或用获准的替代材料。固定文件版本由 S003 导入助手私有空间。历史路径只是定位线索。父会话后续发言经显式交接才可进入子会话，当前任务修订由定向通知投递。 [S003 执行空间](S003.md#workspace)
- 委托记录保存父代理和指定联系人的双方对应关系。助手在给定范围内可与获准的对方成员或助手答疑，发布获准材料及送回草案。父代理记录采用或退回及其来源。首次协商登记、拒绝或撤回即结束该范围。继续服务生效任务须重新授权，撤权和终止都停止相关后续调度或业务写入。
- 参考 Codex 的 `lastTurnId` 和 Pi 的历史谱系建立定点分支。课程平台用 SQLite 持久检查点和可见性投影承载历史，父子的后续写入各自归档。Codex 与 Pi 是机制参考。 [Codex 固定上游提交的分支参数](https://github.com/openai/codex/blob/1476a08f1b410e359e64becf2494bc248743e396/codex-rs/app-server-protocol/src/protocol/v2/thread.rs#L3250) · [Pi 会话结构](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/session-format.md)

## 规格验证与外部条件

- 在三回合都含不同事实的父会话从第二回合建分支，验证获准版本可读，第三回合的私有事实在显式交接前不可见。并行推进父子回合，记录可重叠时间与独立会话 ID。重放建分支请求，复验同一回执和子会话。
- 用未获准的第三成员及获准的助手对照验证上下文、文件、检索、报告及回放。在首次协商、任务修订、撤权和目标终止处检查联系人和工具权限。受控重启后检查旧代次结果无法覆盖当前记录。 [S004 组合验收](S004.md#scenario-validation)
- 正式联调依赖课程端点的真实模型、凭据和配额。用仅第一次工具掌握的值驱动第二次真实调用，确认传输和回传格式。HKGAI 原生工具调用及 DeepSeek 所选模式的历史回传要求以实测为准。未取得条件前可验证离线持久化及模型适配契约。
