# r0002 业务规则确认

项目组成员在本轮讨论中确认了任务写入能力、必需交付和队列激活规则。这三项决定同步至需求和规格。 [更新后的详细需求](../../../../grill_result/agent-collaboration/requirement.md) · [r0001 讨论稿和审阅记录](../r0001/review.md)

<a id="business-decisions"></a>

- **任务创建与更新。** 所有正式角色的主代理均可在授权范围内创建任务和登记修订，包括新增角色。任务生效仍依赖承诺方同版确认，更新还要核对适用的基础修订。
- **必需交付。** 由 Lead 组织确认，将必需交付逐项列入目标验收约定，关联对应任务和当前审查。变更通过修订保留。
- **排队激活。** 活动目标结束后通知 Lead，由 Lead 激活队列中最早满足前置条件的一项。其余目标保留队列位置。

[S001 已确认规则](specs/S001.md#accepted-decisions) · [S004 评测与组合验收](specs/S004.md)

本修订为规格候选。r0001 的规格审阅作为既有记录保留。本轮独立复核覆盖 S001 的任务权限与目标结案、S004 的冻结计数与队列激活，以及与详细需求的对应关系。

<a id="targeted-review"></a>

同一位只读审阅者定点复核了 F002 和 F003。初始及新增角色的任务写入能力、同版确认、必需交付与当前审查的关联、Lead 通知和队列激活均与本轮决定一致，复核通过。覆盖范围为本次决策影响的规格接缝。 [修订与复核输入](revision.json)
