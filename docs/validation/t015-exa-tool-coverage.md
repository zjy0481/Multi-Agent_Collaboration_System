# T015 检索取证与工具执行验证

## 六题实跑

在 `9e2968a` 上叠加 Exa 优先、SearXNG 回退和权限错误指引，使用真实 HKGAI、Docker 与三组全新状态运行六道官方题。同组两题连续进行，每题 30 分钟。四题在平台结案，六题均未通过完整的独立验收。两道截止题分别缺软件看板的正式提交和基金演示的获批终版。四题结案也各有数据交接、来源表述或复核缺口。 [官方题面](<../../test samples/README.md>) · [T015 工单](../plans/agent-collaboration/revisions/r0003/tickets/T015.md)

| 环节 | 实跑记录 | 归因 |
| --- | --- | --- |
| 搜索 | 94 次均由 Exa 返回有效结果，未触发回退。原来使用 SearXNG 的对照轮中，103 次查询均标记为降级。 | Exa 解决了本轮观测到的搜索降级。 |
| 原文提取 | 90 次成功读取。8 次内容类型错误均来自 PDF，共 7 个不同链接。 | 原文工具此前只支持 HTML 和纯文本。 |
| 来源访问 | 45 次 HTTP 403，2 次 HTTP 202。相同会话最多可归并 5 次重复 403。 | 网站访问策略及响应状态会影响取证。 |
| 权限交接 | 新闻组收到依赖错误后调整提案并继续。基金组返工时拿到获批风险原件与获批研究原件的等哈希授权副本，并更新了任务的输入版本。 | 回执指引和既有授权动作可帮助恢复。 |
| 工具执行 | 软件和基金第二题各发生一次单次工具调用超过 8 个的错误。另有一次因默认沙箱缺少 `curl` 失败。 | 已知边界需要在工具说明、错误回执或运行时恢复中体现。 |

新闻模型拿到独立研究后仍误读了统计口径，基金整合稿也出现可复算的不一致。软件看板所需的真实预约数据未交接。六题记录支持将这些交付问题和工具故障分别定位。软件和基金第二题各有 7 次 HKGAI 请求超时，和交接、返工一起影响了进度。

## 本次增量验证

分支同步至 `d5ee8c0` 后，使用真实 Exa 搜索相同 WSTS 查询，从第 3 条结果读取此前无法处理的 PDF，得到 3,692 个字符，并按 `source_id` 取回相同的记录。另独立读取香港金管局 PDF 的 15,084 个字符，以及港科大新闻 HTML 的 11,419 个字符。 [WSTS 原文 PDF](https://www.wsts.org/esraCMS/extension/media/f/WST/7618/WSTS_FC-Release-2026-May.pdf) · [香港金管局 PDF](https://www.hkma.gov.hk/media/eng/doc/key-information/press-release/2025/20251128e7a1.pdf) · [港科大新闻](https://hkust.edu.hk/news/hkust-and-unitree-sign-mou-advance-embodied-ai-and-robotics-collaboration)

真实冒烟覆盖被修复的取证链路。六题的结案与独立评分来自增量修复前的那轮运行。原始 SQLite、trace、产物版本及模型请求记录保留在测试本机的忽略目录。
