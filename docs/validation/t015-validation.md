# T015 官方样例运行记录


本文中的 `.tmp` 路径指原验收机器的本地记录，仓库不会包含这些文件。可按本地环境配置指南运行仓库内测试。
使用 T014 功能分支的验收提交 `69b7f766064353fac4baddc7fffdd28b16c3ceec`。运行使用 HKGAI `t2_hkgai-v3_fp8_1m_e7`、本机 Docker 沙箱和 `127.0.0.1:8888` 的 SearXNG。证据目录为 `.tmp/t015/official-69b7f76`。三个场景分别使用自己的 SQLite 状态和工作空间，每个场景的两题共用一个四角色团队和已有历史。

场景运行器发送官方 `text` 代码块原文，保存每道题的原始消息 ID、题面 SHA-256、平台耗时、报告、工具收据、产物版本和审查记录。测试操作者对实际提出的问题提供模拟答复，并在运行空闲时发送进度补充。每题的首轮观测上限为 420 秒。超过时限由操作者结束未结案目标，并保留结束前的状态。平台因此记录为 `cancelled` 的目标在本报告列为未完成。角色、试题和工单以 [官方样例](<../../test samples/README.md>) 和 [T015](../plans/agent-collaboration/revisions/r0003/tickets/T015.md) 为准。

六道官方题的原文和团队归属均通过逐项校验。六题全部登记，产生 5 项生效委派、4 次正式提交及 17 个不可变产物版本。**在本轮观测窗口内，完整结案与正式审查均为 0。** 各题前后状态、版本 SHA-256 和产物副本路径已保存在 `.tmp/t015/official-69b7f76/summary.json`。

## 新闻组
